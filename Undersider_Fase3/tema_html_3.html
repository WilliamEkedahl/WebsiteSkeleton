HTML - grunnleggende

HTMl i prosessen

HTML- taggene utgjør den grunnleggende strukturen for hva som skal vises på nettsiden. I utgangspunktet ligger elementene i en stabel oppå hverandre. Som et tårn av byggeklosser.

De fleste elementene er block-elementer og tar opp 100% av tilgjengelig plass sideveideis og har ingen høyde. Innholdet i elementet, for eksempel bokstaver vil gi dem høyde. Inline-elementer tar så liten plass de kan sideveis, det er innholdet som gir dem bredde. Inline-elementer er gjerne beholdere for tekst som «p», «h1-h4» taggene. Og «span» som kan brukes for å påvirke utvalgte deler av teksten.

Når vi skal skrive html er det mye lettere om vi har en klar ide om hva vi forsøker å skape. Vi kan for eksempel bruke grafikkprogrammer som Adobe Photoshop og konstruere bilder som viser hvordan vi ser for oss at nettsiden skal se ut. Det er mye raskere å lage en visuell fremstilling i et slikt program enn å skrive html og CSS for å se hvordan nettleseren presenterer koden.

Planlegging gjennom visuell fremstilling

Figma er et grafikkprogram med funksjonalitet for å lage visuelle fremstillinger av internettsider nettopp for å kunne planlegge og bli enige med hverandre om hvordan det ferdige resultatet skal se ut.

Selv om HTML er de første nødvendige bygeklossene i den digitale representasjonen som netlleseren forholder seg til, er ikke skriving av HTML først skritt i prosessen med å lage nettsider.

Med digitale modeller kan vi vise hverandre og kundene hva vi har tenkt, og få tilbakemeldinger vi kan justere oss etter før vi har kodet. Vi kan også presentere egne ideer uten å bruke lang tid.

Kilder til kunnskap
Det finnes mange gode forum på nettet der likesinnede deler sine frustrasjoner, problemer, kunnskaper og løsninger. Webutviklere har lang tradisjon for samarbeid og utvikling gjennom refleksjon, prøving og feiling. I tillegg er finnes det dokumentasjon som forteller og forklarer hvilke egenskaper utviklerne kan benytte seg av, og vi kan anbefale w3schools.

Verktøy for jobben
Selv om det er teoretisk mulig å skrive koden i et hvilket som helst tekst-redigeringsprogram som Notepad eller Word, er det utrolig tregt, arbeidsomt og kjedelig. Gode kodeprogram kommer i mange varianter. De hjelper deg ved å sette forskjellig farge på teksten avhengig av hvilken rolle teksten har i koden. Og det er til stor hjelp.

Emmet

Når du skal skrive HTML finnes det et veldig praktisk programtillegg som heter Emmet. Emmet er integrert flere kodeprogram og finnes ellers fortsatt som tillegg. Emmet aksepterer små koder som forteller hvilke elementer du vil lage. Du skriver litt, Emmet skriver masse for deg.

Videre lesning

Vi ønsker å inspirere og være til hjelp for deg som er interessert i å lære mer om web-utvikling.

Som du ser i topp-menyen er det mange aspekter ved webutvikling, ikke la det overvelde deg. Alt henger sammen og endringer kan gjøres underveis i prosessen.

Universell Utforming

Hva er Universell Utforming

Universell utforming, forkortet som UU, handler om å lage løsninger som alle kan bruke, uansett hvilken nedsatt funksjonsevne en person kan ha. Universell utforming innebærer alt av å designe bygg, produkter, tjenester og omgivelser på best mulig måte sånn at det kan brukes av alle. Målet med Universell utforming er å kunne redusere eller fjerne barrierer som kan hindre deltakelse gjennom utforming som sosiale og kulturelle institusjoner, bygde omgivelser og IKT (Lid, 2024).
